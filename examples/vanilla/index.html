A real gapless and crossfade scheduler, loudness matching from ReplayGain tags, and a live spectrum, all in the browser. Whatever you feed it is decoded and resampled to your system rate, so this is not bit-perfect and does not pretend to be.
eko-web on GitHub

EKO Web, vanilla JS demo: the eko-web engine driven directly, with no framework and no binding layer. There is no re-render to lean on here, so this page subscribes to the engine itself and patches the DOM by hand: engine.subscribe(fn) for discrete state (title, queue position, play/pause, volume) and engine.on("timeupdate", fn) for the clock, which is exactly what useEkoPlayer and useEkoTime do under the hood in the React and Vue demos. Pick a short file, or press Use a test tone. Switch Gapless, Crossfade and Gap to hear the seam change; with a single file the queue holds it twice so there is a real boundary to hear. The GAIN readout says whether the loudness match came from a ReplayGain tag in the file or from the engine measuring the decoded audio itself.
