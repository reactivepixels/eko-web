eko-web harness

Pick a short loop, or press Use a test tone if you have nothing to hand. Then press play and listen at the seam. Adjust the transition mode and other controls to hear the differences.

Play is disabled until audio is loaded. Transition modes: gapless abuts tracks with no silence; crossfade overlaps them smoothly; gap leaves silence between. With crossfade, the overlap time is adjustable. Shuffle randomizes playback order without repeating tracks. Repeat one plays a single track in a loop, all loops the entire queue. Source forces the playback strategy: buffer decodes the whole file and is the only path that can be gapless, while element streams and never is, so on element you should hear a seam even with gapless. On auto a local file always takes the buffer path. The test tone is a continuous 440 Hz sine of exactly 880 cycles, so its loop point is phase continuous: with gapless on you should hear one unbroken tone, and with gap mode a click every two seconds. Every file you pick is read for a ReplayGain tag (@rpxl/eko-web/replaygain) before it's queued, and the loudness source readout says which number the engine is actually using: tag when the file carried a ReplayGain gain, measured when it didn't and the engine analyzed the decoded audio instead. The test tone carries no tag, so it always reads measured.
