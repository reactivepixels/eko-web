Pick a short loop, or press Use a test tone if you have nothing to hand. Then press play and listen at the seam. Untick gapless to hear the gap appear.

Play is disabled until audio is loaded. source forces the playback strategy: buffer decodes the whole file and is the only path that can be gapless, while element streams and never is, so on element you should hear a seam even with gapless ticked. On auto a local file always takes the buffer path, because the size probe cannot read a blob URL. The test tone is a continuous 440 Hz sine of exactly 880 cycles, so its loop point is phase continuous: with gapless on you should hear one unbroken tone, and with it off a click every two seconds. Any click you hear with gapless on is the engine, not the file.
