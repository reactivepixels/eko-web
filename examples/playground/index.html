What this is

Toys with a point: every player here drives the same engine you install, with no mocks underneath. The skins change; the playback doesn't.

Run it

From the repo root, npm run harness, then open /examples/playground/. Players import the built dist/.

More

The plain reference player is in examples/player, and the framework bindings in react and vue.
