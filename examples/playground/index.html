What this is

Toys with a point. Every player here drives the same engine you install, with no mocks underneath. The skins change; the playback doesn't.

Bring your own music

Each player plays a generated set out of the box. Drop audio files on any of them, or open some, and it plays them instead. Nothing is uploaded: the files never leave your browser.

The source

Every player is plain HTML and JavaScript, no build step, in examples/playground. Install the engine with npm install @rpxl/eko-web.
